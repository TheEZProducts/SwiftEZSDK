# EZSDK

1. [EZHelpersKit](EZHelpersKit/README.md) - Набор полезных инструментов
2. [EZAsyncKit](EZAsyncKit/README.md) - Модуль облегчающий работу с async/await
3. [EZUIPackKit](EZUI/EZIMVPack/EZUIPackKit/README.md) - Модуль для построения UI по архитектуре IMV (Interactor–Mediator–View)
4. [EZSUIPackKit](EZUI/EZIMVPack/EZSUIPackKit/README.md) - SwiftUI модуль для построения UI по архитектуре IMV
5. [EZSwiftUIBridgeKit](EZUI/EZSwiftUIBridgeKit/README.md) - Инструменты для встраивания UIKit/AppKit view в SwiftUI и наоборот
6. [EZTransitionKit](EZUI/EZTransitionKit/README.md) - Система кастомных переходов между экранами
